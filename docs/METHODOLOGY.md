## 1. 工作模型

```
H(t) = F( G, E₀→t, H(t−1), ε ; R )
```

| 符号 | 含义 | 在项目中的体现 |
|---|---|---|
| H(t) | 人在时刻 t 的状态向量（8 层、126 维） | `DIMENSIONS`、个人画像 |
| G | 基因组 | L1 层维度；ACE 中的 A |
| E₀→t | 一生暴露史 | L6 层维度；ACE 中的 C 与 E |
| H(t−1) | 路径依赖 | 模拟器逐年推进；人生事件 |
| ε | 不可约随机性 | 蒙特卡洛抽样；混沌演示；克隆小鼠证据 |
| R | 反身性 | 反身性实验室；预测账本 |

## 3. 人生里程表（`src/engine/lived.ts`）

按 0.25 年步长对年龄依赖的速率积分：心率（新生儿 130 → 成人静息心率 + 10）、呼吸频率（40 → 14 次/分）、睡眠（14.5 → 成人自报时长）。
说话量 1.6 万词/天（Mehl 2007），步数 6000 步/天（示意），意识带宽 10 bit/s（Zheng & Meister 2025）。只有出生年份时按年中出生估算。

## 4. 寿命模型（`src/engine/mortality.ts`）

### 4.1 基线
Gompertz–Makeham 风险函数：

```
μ(x) = λ + α · HR · e^(βx)
S(x) = exp( −λx − (α·HR/β)(e^(βx) − 1) )
```

- β = 0.09（死亡率约每 7.7 年翻倍；文献常见范围 0.085–0.11）
- λ = 0.0003（与年龄无关的背景死亡）
- α 按性别二分法校准，使出生预期寿命 = 男 76.3 / 女 81.8 岁（对应中国 2024 年人均预期寿命约 79 岁，性别差约 5.5 岁的量级）
- 条件生存：S(x | 已活到 a) = S(x)/S(a)

### 4.2 风险因素（相对“理想参考水平”的风险比）

| 因素 | 剂量-反应 | 来源 |
|---|---|---|
| 吸烟 | 从不 1.0 · 已戒 1.3 · 吸烟 2.0 | Jha 2013；Chen 2015（中国） |
| 运动（分钟/周） | 0→1.45 · 75→1.16 · 150→1.0 · 300→0.91 · 450–750→0.88 · 1200→0.93 | Arem 2015 换算 |
| BMI | 22.5–25 为 1；>25 每 5 单位 ×1.29；18.5–22.5 每单位 +5%；<18.5 陡升 | PSC 2009 |
| 睡眠 | 7–8h 为 1；6h 1.08；5h 1.15；9h 1.12；10h 1.3 | Cappuccio 2010 |
| 饮酒（杯/周） | ≤7 为 1；14→1.05；28→1.18；42→1.35 | Zhao 2023 |
| 社会支持（1–5） | 1→1.35 · 3→1.08 · 4→1.0 · 5→0.96 | Holt-Lunstad 2010/2015 |
| 饮食（1–5） | 1→1.25 · 3→1.06 · 5→0.9 | Sofi 2010；GBD 2019 |
| 目的感（1–7） | 1→1.1 · 4→1.0 · 7→0.91 | Cohen 2016 |
| 尽责性 z | exp(−0.09 z) | Jokela 2013 量级 |

### 4.3 合并与归一化

```
logHR_ind = 0.7 × ( Σ log HR_i − E_pop[ Σ log HR_i ] )
```

- **0.7 收缩**：风险因素彼此相关（吸烟者更少运动……），观察性 HR 含混杂，直接相乘会高估。
- **人群归一化**：基线生命表代表的是“人群平均”，而非“理想人”。因此减去人群典型组合的期望 log HR（男性现吸烟率约 50%、女性约 2%；运动 60 分钟/周；BMI 24.3；睡眠 7h；饮酒 男 7 / 女 1 杯；社会支持 3.5；饮食 3；目的感 4.5；尽责性 0），使“典型的人”HR≈1。测试中验证了这一点。

### 4.4 杠杆排序
对每个因素：仅把该因素设为理想值（其余不变）重新计算剩余预期寿命，差值即“杠杆”。由于收缩与归一化，各杠杆之和不等于全部理想时的总增益。

## 5. 蒙特卡洛人生模拟（`src/engine/simulate.ts`）

逐年推进三个状态量，种子固定可复现（mulberry32）。

**健康 h**
```
h = clamp( 100 − √HR · D(age) − chronic − acute + noise, 1, 100 )
D(age) = Σ_{a=20}^{age} [0.15 + 0.02·max(0, a−35)]
noise_t = 0.7·noise_{t−1} + N(0, 2²)
```
重大疾病年概率 `min(0.2, 0.004·e^(0.06(age−30))·HR^0.7)`；每次冲击 10–25 点，60% 为急性（每年衰减 35%），40% 为永久。

**死亡**：年死亡概率 `1 − exp(−μ(age+0.5))`，μ 中的 HR 再乘以 `exp(0.04·(acute − E[acute]))`——近期患病者风险更高，但人群平均与生命表保持一致。

**幸福感 wb（0–10）**
```
wb = lifeSat + U(age) − U(age₀) + 永久变化 + 暂时变化 + 0.02·(h − h_base) + N(0, 0.35²)
U(age) = 0.0004·(age − 48)²       # Blanchflower 2021 U 形，幅度约 0.4
暂时变化每年衰减 50%（享乐适应，Lucas 2007）
```
事件效应（暂时 / 永久）：伴侣 +0.8/+0.1；孩子 +0.5；离婚 −1.2/−0.15；丧偶 −2.0/−0.3；丧亲 −1.0；失业 −1.0/−0.2（失业的持久影响见 Lucas 2007）；重病 −1.2/−0.3；意外之喜 +0.8；退休 +0.3。

**收入百分位 w（1–99）**：向目标值均值回归（速率 0.15/年）+ N(0, 3²) + 事件冲击；目标值 = 当前百分位 + 年龄曲线（50 岁达峰）+ 教育与尽责性的缓慢效应 − 退休 8 点。

**事件年概率（示意，待校准）**：伴侣形成 20 岁前 1% · 20–35 岁 12% · 36–50 岁 4% · 之后 1.5%；生育（有伴侣、育龄、最多 2 个）9%；离婚 50 岁前 1.2% · 之后 0.5%；伴侣死亡按异性生命表；父母死亡按生命表（假设父母比你大 30/28 岁）；职业转换 8%；失业 2.5%；意外之喜 1.2%；搬迁 35 岁前 6% · 之后 2%；退休 男 63 / 女 58 岁。

## 6. 混沌（`src/engine/chaos.ts`）

洛伦兹系统 σ=10, ρ=28, β=8/3，RK4 积分 dt=0.005。最大李雅普诺夫指数 λ≈0.906。预测地平线 `T = ln(Δ/δ₀)/λ`：精度每提高 10 倍，地平线只延长 ln10/λ ≈ 2.54 个时间单位。

## 7. 反身性实验室（`src/pages/Limits.tsx`）

结果概率对公开预测 p 的反应：`q(p) = clamp(p₀ + β(p − 0.5), 0, 1)`。自洽预测为 q(p)=p 的不动点。β<0（逆反）时唯一不动点偏离 p₀；β>1（强顺从）时出现多个不动点——预言可以自我实现。这是一个说明性的玩具模型。

## 8. 预测账本（`src/engine/ledger.ts`）

- Brier 分数 `BS = mean((p − o)²)`；Murphy 分解 `BS = 可靠性 − 分辨力 + 不确定性`（5 个等宽概率箱）
- 过度自信 = 平均把握度 max(p, 1−p) − 实际命中率

## 9. 八层综合分（`src/engine/scoring.ts · layerScores`）

透明的启发式，仅用于可视化对比，未经验证：
- L0 能量平衡：100 − min(60, |BMI − 22.5| × 8)
- L2 生理活力：(体能分 + (70 − 60·ln HR)) / 2；体能分 = min(100, 运动/300×70 + (90 − 静息心率)×1.2)
- L3：睡眠分×0.7 + min(100, 受教育年限×5)×0.3
- L4：50 − 15·z(神经质) + 10·z(尽责性)
- L5：生活方式分×0.6 + 体能分×0.4
- L6：支持/5×50 + min(5, 亲密关系)×6 + (5 − 孤独)×5
- L7：满意度/10×40 + 目的感/7×35 + 意义/10×25
- L1：无数据，留空
