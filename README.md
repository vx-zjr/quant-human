# 人类量化图谱 · Quantified Human Atlas

> 尽可能把“人”从物质到意义拆成可测量的维度——解构、解读、解释、解析、预测——同时诚实地标出科学的边界。

**在线访问：<https://vx-zjr.github.io/quant-human/>**

**核心结论**：人在统计上高度可预测，在个体上深刻不确定。量化的正确目标不是“预言”，而是**校准良好的概率分布**。

## 功能

| 页面 | 动词 | 内容 |
|---|---|---|
| 总览 | — | 工作模型 H(t)=F(G,E,H(t−1),ε;R)、五个动词 × 三个时态、八层同心圆、量化与预测的鸿沟 |
| 维度图谱 | 解构 | 126 个维度的旭日图、筛选、详情（测量方法 / 可测量性 / 遗传度 / 稳定性 / 预测价值 / 文献） |
| 理论框架 | 解构 | 17 个框架（生物-心理-社会、大五、SDT、埃里克森、自由能原理……）含实证评级与批评 |
| 个人画像 | 输入 | 身体、生活方式、20 题大五问卷、价值观、PERMA、社会关系、时间分配、人生事件 |
| 过去 · 解构 | 解释 | 实时人生里程表、发展阶段时间轴、ACE 方差分解、身体细胞“年龄层” |
| 现在 · 解读 | 解读 | 八层仪表盘、规则式解读、元素构成、人格百分位、价值观圆环、邓巴圈 |
| 未来 · 预测 | 预测 | 寿命模型与生存曲线、杠杆排序、情景模拟、蒙特卡洛平行人生 |
| 可预测性极限 | 解析 | 洛伦兹混沌、信息尺度、缺失遗传度、真实预测研究、反身性实验室 |
| 预测账本 | 预测 | 记录对自己的预测，Brier 分数与校准曲线 |
| 看法与建议 | — | 七个核心判断、伦理红线、路线图 |

所有个人数据只保存在浏览器本地。非医疗/心理诊断工具。

## 开始

```bash
pnpm install
pnpm dev        # http://localhost:5173
pnpm check      # 类型检查 + 测试 + 构建
```

## 如何迭代

本项目由 [`AGENT.md`](./AGENT.md) 驱动：它定义了北极星、红线、目录结构、扩展指南与每轮迭代的协议。
任务清单在 [`ROADMAP.md`](./ROADMAP.md)，历史在 [`CHANGELOG.md`](./CHANGELOG.md)，模型公式与假设在 [`docs/METHODOLOGY.md`](./docs/METHODOLOGY.md)。

给智能体的一句话指令示例：

> 阅读 AGENT.md，按迭代协议完成 ROADMAP 中下一项任务。

## 部署

推送到 `main` 分支后，GitHub Actions（`.github/workflows/deploy.yml`）会自动执行 `pnpm check`（类型检查 + 测试 + 构建），全部通过后发布到 GitHub Pages。检查失败则不会发布。
